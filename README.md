# 🤖 Telegram Survey Bot с Админ-панелью

Профессиональный бот для проведения опросов с мощной административной панелью и **встроенной защитой от атак**.

---

## ⭐ Почему этот бот лучше других?

### 🛡️ БЕЗОПАСНОСТЬ (главное отличие!):
- ✅ **Защита от DDoS/DoS атак** — бот не упадёт от спама
- ✅ **Антифлуд** — макс 10 запросов за 10 секунд от одного пользователя
- ✅ **Защита от перебора пароля** — 3 попытки → блокировка на 5 минут
- ✅ **Зашифрованный пароль админа** — SHA256 хеширование
- ✅ **Автоматическое удаление** команды `/admin` и пароля из чата

### 🎯 Что умеет бот

#### Для пользователей:
- 📝 Прохождение опросов с удобным интерфейсом (Inline-кнопки)
- 📊 Просмотр своих результатов
- ✅ Автоматическое сохранение ответов

#### Для администратора:
- 📊 **Статистика** — количество пользователей, завершённых опросов, ответов
- 👥 **Управление пользователями** — просмотр всех пользователей бота
- 📥 **Экспорт данных** — выгрузка всех ответов в CSV для Excel
- 📢 **Рассылка** — отправка сообщений всем пользователям
- 🔐 **Защищённый доступ** — только администратор может войти в админ-панель

## 🚀 Быстрый старт (3 шага)

### Шаг 1: Создайте бота в Telegram

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте токен (например: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Настройте токен и пароль

1. Откройте файл `.env.example` в блокноте
2. Вставьте **ваш токен** бота и **смените пароль**:
   ```
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ADMIN_PASSWORD=ваш_секретный_пароль
   ```
   ⚠️ **ВАЖНО:** 
   - Используйте СВОЙ токен от @BotFather
   - ОБЯЗАТЕЛЬНО смените `admin123` на свой пароль!
   
3. Сохраните файл (Ctrl+S)
4. Переименуйте `.env.example` в `.env`

### Шаг 3: Запустите бота

**Дважды кликните на файл `start.bat`**

Скрипт автоматически:
- ✅ Создаст виртуальное окружение
- ✅ Установит все зависимости
- ✅ Запустит бота

Готово! 🎉

## ⚙️ Настройка опроса

Откройте файл `handlers.py` и найдите блок `SURVEY_QUESTIONS` (примерно строка 50).

Там легко изменить вопросы:

```python
SURVEY_QUESTIONS = [
    {
        'question': '1️⃣ Ваш вопрос здесь?',
        'answers': ['Вариант 1', 'Вариант 2', 'Вариант 3']
    },
    {
        'question': '2️⃣ Второй вопрос?',
        'answers': ['Да', 'Нет', 'Не знаю']
    }
    # Добавьте сколько угодно вопросов
]
```

**Изменения применяются после перезапуска бота!**

## 🔐 Как войти в админ-панель

1. Откройте вашего бота в Telegram
2. Отправьте команду `/admin`
3. Введите пароль из файла `.env` (по умолчанию: `admin123`)
4. Готово! Теперь у вас доступ ко всем админ-функциям

## 💾 База данных

Бот использует **SQLite** — всё хранится в файле `survey_bot.db`.

**Таблицы:**
- `users` — информация о пользователях
- `survey_responses` — ответы на опросы
- `user_survey_state` — прогресс прохождения опроса

Никаких сложных настроек не требуется!

## 🐛 Решение проблем

### Python не найден
```bash
# Скачайте Python с python.org
# При установке поставьте галочку "Add Python to PATH"
```

### Ошибка при установке библиотек
```bash
# Обновите pip вручную
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Бот не отвечает
- ✅ Проверьте токен в `.env`
- ✅ Убедитесь что `start.bat` запущен
- ✅ Проверьте интернет соединение

### Не могу войти в админку
- ✅ Проверьте пароль в `.env`
- ✅ Команда должна быть `/admin` (слэш обязателен)
